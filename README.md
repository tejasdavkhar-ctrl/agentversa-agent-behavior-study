# AgentVersa Agent Behavior Study

## Student / Researcher Role
This portfolio documents the work of a student researcher studying agent behavior in simulated multi-agent scenarios. The work is designed as an educational case study and research notebook rather than a production evaluation of a deployed system.

## Short Description of AgentVersa
AgentVersa is a simulated environment for studying how autonomous or semi-autonomous agents behave when assigned roles, given information, constrained authorities, and interactions with other agents. It is useful for exploring decision-making, cooperation, conflict, risk handling, and role adherence in structured scenario-based tasks.

## Research Question
How do agent behaviors vary across scenarios when agents are given different roles, information, permissions, and social relationships, and what patterns of decision-making, risk assessment, cooperation, and failure emerge under those conditions?
